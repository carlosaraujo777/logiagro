# 🌱 LogiAgro | Marketplace de Frete Agrícola

O **LogiAgro** é uma plataforma web (MVP) que conecta produtores rurais a caminhoneiros, resolvendo um dos maiores gargalos do agronegócio: o frete de retorno vazio e a dificuldade de escoar a safra no tempo certo.

## 🚀 O Problema
No agronegócio brasileiro, o produtor frequentemente perde dinheiro porque o transporte não chega a tempo (e a safra estraga). Ao mesmo tempo, caminhoneiros voltam vazios de regiões produtoras, perdendo a oportunidade de um frete de retorno lucrativo.

## 💡 A Solução
Uma interface simples e direta onde:
1. O **Produtor** cadastra a carga (produto, origem, destino e peso).
2. O **Caminhoneiro** acessa a plataforma, visualiza os fretes disponíveis na região e aceita a carga.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica das telas (Produtor e Caminhoneiro).
- **CSS3:** Design responsivo e limpo, focado na usabilidade (Mobile First).
- **JavaScript (Vanilla):** Lógica de troca de abas, cadastro e remoção de fretes.
- **LocalStorage API:** Persistência de dados simulando um banco de dados, permitindo que as cargas fiquem salvas no navegador.

## 💻 Como testar localmente
1. Clone este repositório.
2. Abra o arquivo `index.html` no seu navegador.
3. Cadastre uma carga na aba "Sou Produtor".
4. Vá para a aba "Sou Caminhoneiro" e veja a carga aparecer.
5. Clique em "Aceitar Frete" e veja a mágica acontecer.
